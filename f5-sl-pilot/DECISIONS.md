# SL 当前实验规则

本文定义SL与SH不同的规则，依据《执行单：f5-sl-pilot》（[docs/执行单-f5-sl-pilot-2026-10-31.md](docs/执行单-f5-sl-pilot-2026-10-31.md)）；与原稿《A5 SL任务pilot》不一致处以执行单为准。其余规则（正式流程、理解题页与量表、教程工具说明、界面文字、U2休息机制与主试提醒、数据记录与导出、呈现模式、配置格式）沿用 [SH的DECISIONS](../f5-sh-pilot/DECISIONS.md)，不另做改动。

## 与SH不同的规则

1. **没有补充资料附件，U1没有E。** 不要求查看附件即可提交；导出中E、F相关字段为空。
2. **T0**：U1中非空作答项数量**第一次达到3个**后2秒送达。“填完”以输入框失去焦点为准（单选以选中为准）；之后清空或修改不重新计算，每组最多一次。不论填的是哪三题。
   - 服务端记录 `answers_threshold_reached`（含非空作答项数、字段、触发方式blur）、`t0_planned`、`t0_due`；消息的 `event_elapsed_ms` 是 `t0_due` 时刻，即阈值事件后2000毫秒。
   - 所有任务组（含NONE、T1、T2组）都记录阈值事件，只有T0组据此送达消息。
   - 暂停冻结这2秒计时。到点时眼镜未就绪或上一条未结束：不覆盖、不排队、不补发，记为发送失败及原因（`device_not_ready_at_t0` / `previous_message_pending`），与T2的处理一致。
   - 配置在 `content/tasks.json` 的 `t0_trigger`（`answers_filled`，`min_answers: 3`，`delay_ms: 2000`）；SH没有此字段，沿用“U1附件首次实际呈现”。
3. **T1**：U2首次实际呈现时送达（同SH）。
4. **T2**：U2自主休息，窗口下限**10秒**（SH为30秒），休息30秒，休息页可见后5秒送达。
5. **教程顺序**：工具说明 → 练习单元1（东侧书架）→ 练习单元2（西侧书架，含休息练习）→ 含持续确认模式时的练习消息与理解题 → 情景导入。练习单元2的休息窗口下限5秒、休息5秒，须休息过一次才能提交。练习单元必答、不判对错，数据标记tutorial。练习后的消息练习由 `tutorial_notice_after_practice` 开启；没有持续确认模式的会话直接进入情景导入，消息练习仍可由主试在后台手动发送。
6. **作答与评分**：所有作答项必答。SL05为单选（正确／错误），其余为非负整数。**逐项判分**，每个单元记录每项对错（`unit_scored` 事件的 `item_results`、`max_score`）和答对数（0—8）。导出的 `trials.csv` 在有逐项评分时增加 `max_score`、`item_results` 两列，`score` 为答对数；SH的导出不变。完整错误答案仍可提交，不向被试提示正误。
7. **情景时间**显示在情境时钟，不写进说明卡正文。
8. 题干每一行对应 `paragraphs` 中的一个段落，符号“=”“−”“×”“÷”“+”原样写入；表格不设“题号”列，也没有表格标题或文件名条；作答项标签为“事项名称（单位）”，顺序与表格行一致（SL03的名称已含单位，SL05的标签为事项名称）。
