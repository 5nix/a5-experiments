## 一、实现要求

- 以 `f5-sh-pilot` 完成《执行单-被试文本修改》后的版本为基础复制，`experiment_id` 为 `f5-sl-pilot`。在新分支完成，`npm run check` 通过后推送。
- 以下沿用SH，不另做改动：正式流程、理解题页与量表、教程中的工具说明和练习消息、界面文字、U2休息机制与主试提醒、数据记录与导出、呈现模式、配置格式。
- 与SH不同的规则：
  1. 没有补充资料附件，U1没有E。
  2. T0：U1中非空作答项数量第一次达到3个（以失去焦点计）后2秒送达。
  3. T1：U2首次实际呈现时送达（同SH）。
  4. T2：U2自主休息，窗口下限10秒，休息30秒，休息页可见后5秒送达。
  5. 教程顺序：工具说明 → 练习单元1 → 练习单元2（含休息练习）→ 含持续确认模式时的练习消息与理解题 → 情景导入。练习单元2代替SH的独立休息练习页。练习单元2中休息窗口下限5秒、休息5秒，须休息过一次才能提交。练习单元必答、不判对错，数据标记tutorial。
  6. 作答与评分：所有作答项必答。SL05为单选（正确／错误），其余为非负整数。逐项判分，记录每项对错和单元答对数（0—8）。
  7. 情景时间显示在情境时钟，不写进说明卡正文。
- 题干每一行对应 `paragraphs` 中的一个段落；符号“=”“−”“×”“÷”“+”原样写入。
- 表格不设“题号”列；作答项标签为“事项名称（单位）”，顺序与表格行一致。
