# F0-photo-V1.0-1014

从最新版 F0-photo-test-V1.0-1014 复制，内置本次附件表格的 12 条原文，按数字 id 1—12 升序显示。除材料、数量及对应程序标识外，实验流程、指导语、排版和声音保持一致。

此包为 Android Studio 源码工程，不包含 APK、构建缓存、旧实验数据或 scrcpy 安装包。独立应用标识为 `com.example.f0photo.main`，可与 test 版并存。

## 安装与运行

1. 解压，用 Android Studio 打开本工程，完成同步后以绿色三角 Run 安装运行到眼镜，不要以 Debug 启动。
2. 将已有完整 scrcpy Windows 安装文件放入 `tools/scrcpy`，或把其目录加入 PATH。保留 adb、DLL、server 等配套文件。
3. USB 连接并授权后，双击本工程的 `01_start_preview.bat`。
4. 在外部显示器上打开背景照片；照片由实验人员切换，本程序只控制眼镜文本。
5. 保持电脑控制窗口选中，按空格开始。也支持眼镜直连实体键盘。

启动脚本保留解除“等待调试器”的处理，重新启动本应用后回到指导界面；不会启动 test 或长文本 C 程序。自动预览使用 `scrcpy --crop 640:480:0:0 --no-control`，支持音频转发时添加 `--no-audio`，让声音保留在眼镜。实验中不要重复运行启动脚本，以免返回开头。
