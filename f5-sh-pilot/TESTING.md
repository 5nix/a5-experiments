## Windows 11 软件验收（2026-10-19）

Node.js 24.22.0、npm 11.19.1；`npm ci`、类型检查、33 项实验测试、doctor 和 7 项启动器测试通过。批处理入口、启动/重启/停止、后台进程、浏览器打开、中文及空格路径和 SQLite 完整性均已验证。

Chrome + Playwright 使用临时 runtime：被试端 1536×864 完成 10 单元、4 份理解题、4 份问卷，最终为 COMPLETED，无控制台错误；管理端 1440×900 和 390×844 验证创建、重复会话提示、暂停恢复、结束、删除恢复和 ZIP 导出。重复创建返回 409 是预期的接口拒绝。

修复 Windows `core.autocrlf=true` 将 PRD 换行转换后导致材料哈希不匹配、服务拒绝启动的问题：通过 `.gitattributes` 固定该材料文件为 LF，保留原有 SHA-256 校验，并加入启动自检回归测试。启动器测试的清理对 Windows 短暂目录锁增加有限重试。
