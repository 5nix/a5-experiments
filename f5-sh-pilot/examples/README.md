# Mock 完整流程导出样例

mock-complete.zip完全由程序生成，为合成软件验收数据，不是真实被试结果。采用sh-current-2026-10-19-v3内容，包含5组10单元、4次Mock消息、4份问卷、4次休息（其中一次演示跳过）、计算草稿及一条备注。包含六类CSV/JSONL、文本表格内容快照和导出清单，行数以manifest.json为准。

样例使用001合成数据，is_debug=false；真实调试测试者000的数据会标is_debug=true。休息采用注入时钟，不必实际等待；运行服务默认180秒，也可显式跳过并记录实际时长。

Mock没有真实显示或消失回执，相应时间保持空值。文件仅演示导出格式及关联关系。
