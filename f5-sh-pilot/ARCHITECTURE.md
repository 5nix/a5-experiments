# f5-sh-pilot 核心架构

当前交付以服务端功能、完整软件流程、基础HTML可用和简单测试为范围。行为依据依次为最新用户指令、DECISIONS.md、原始PRD；内容已采用新版XLSX及批准的M1—M6修订，并继续配置化。

## 组成

| 文件或目录 | 职责 |
| --- | --- |
| src/server.ts | 本机启动、持久化路径、实验员凭据、正常停止 |
| src/app.ts | HTTP接口、实验员与被试访问隔离、静态文件白名单 |
| src/engine.ts | 会话状态机、操作去重、时钟、补充资料E、F、问卷和休息、消息调度 |
| src/store.ts | SQLite事务、会话快照、只追加事件、消息发送记录、配置 |
| src/tasks.ts | 内容载入、输入归一化、完全匹配评分、排班约束验证 |
| src/export.ts | 六类导出、完整快照、清单、ZIP及CSV公式前缀处理 |
| src/adapters/mock-glasses.ts | 当前Mock请求回执；不显示桌面消息，不控制关闭 |
| content/tasks.json | 说明卡、题干、文本表格及来源、全任务草稿本配置、字段、答案/约束、量表、时长 |
| content/stimuli.json | 当前消息、理解题、正确答案与来源 |
| public/ | 只负责呈现和调用接口的基础HTML/CSS/JavaScript |

运行依赖为Node.js 24+和fflate，TypeScript用于检查类型。Node直接运行可擦除的TypeScript语法；SQLite使用Node内置模块，不引入需针对操作系统编译的第三方数据库模块。所有运行路径用Node路径接口处理。macOS开发和运行已验证，Windows待实机验证；真实眼镜SDK的系统限制隔离在适配器中。

本实验通过自身package.json声明启动、检查和测试命令，通过自身tsconfig.json确定检查范围，继承仓库tsconfig.base.json的公共选项。材料转换工具位于本实验scripts目录；根目录仅安装公共开发依赖和汇总工作区检查，不默认启动SH。

## 状态与提交

INTRO → CARD → UNIT U1 → UNIT U2 → COMPREHENSION → RATINGS → BREAK → 下一组CARD。NONE在U2提交后跳过两页问卷。最后一组结束直接COMPLETED，无第五次休息。另支持人工暂停和ABORTED，干预必须记录原因。

服务器持有权威状态和必答校验。浏览器先报告当前页实际可见，再提交操作；每页有不可猜测的page_token，旧页面不能继续提交。command_id在数据库中唯一，同一操作重试不会重复写答案、评分或推进页面。

所有主任务与问卷均必答。多选集合与互斥选项、整数、金额、时间和“不适用”各有格式校验；格式正确但答案错误仍允许提交。评分及正确选项只在服务端保存，不返回被试接口。SH04逐项检查资格、到岗时间、缺席及人员互斥，允许多个可行解。

各U1题干已明确要求查看补充资料，因此提交前检查其实际展示；防止未发生E却直接提交。F只在SH05 U1首次完整正式提交时记录，与得分无关。

## 实际可见事件与消息

基础HTML先将Excel单元格文本放入原生table；旧快照图片仍等待解码，待页面可见并完成两个requestAnimationFrame后上报displayed。展开资料同样等待表格DOM（旧图片需解码）及浏览器绘制后报告reveal_displayed。事件保存客户端ISO时间、performance.now、timeOrigin和可见性，服务端同时记录接收时刻；客户端绘制证据与服务器接收时间不能混同。

T0只在第一次reveal_displayed产生发送意图；T1只在第一次u2_displayed产生发送意图。NONE不产生消息。数据库中每个session/stage最多一条消息，先事务保存请求及request_id，再非阻塞调用适配器。设备回执、状态失败和实际显示/消失分别留痕。

请求包含期望duration_ms=8500。8.5秒由展示端独立运行；本程序没有关闭、清除、缩短或重置展示的调用，也不因提交或进入问卷等待展示结束。当前Mock只模拟接受、延迟、断连、无回执；t_display/t_hide为null，source明确为mock。真实设备呈现能力及发送失败后的现场处置待接口提供后确认，软件不以Mock通过宣称真实呈现通过。

## 持久化与恢复

SQLite启用WAL、synchronous=FULL及事务。会话状态变更、事件、发送意图和操作ID在事务中保存。事件表用触发器禁止更新/删除。数据库位于runtime目录；源码、原始材料不与实验数据混放。

创建会话时固定当前题库、消息库、被试配置、文本表格内容及来源哈希（旧会话另有原图字节和哈希）。后续更改源文件不会改变已有会话看到的内容。答案和计算草稿按单元逐次保存，刷新或恢复入口重新加载相同page_token和草稿。原图也从会话快照读取，不读取后来被替换的工作文件。

同一进程中相对时间用服务器单调时钟计算。重启时以持久化相对时间和从开始至今的墙上时间较大值衔接，并记录server_restarted；浏览器刷新另记app_resumed及客户端timeOrigin。恢复时间轴含停机时间，不声称跨进程存在同一个物理单调时钟。已完成会话的主流程总时长在结束时固定，后续访谈仍有独立事件时间。

若重启时存在尚无最终回执的发送记录，标为unknown并记录异常，绝不自动重放。真实硬件没有幂等保证前，不能同时承诺崩溃窗口内“必达且不重复”；异常记录供现场联调处理，不伪造成已显示。

## 实验员与导出

后台凭据首次生成，存于runtime/admin-key，完整链接仅打印在启动终端。被试每会话有独立凭据，只能获得当前公开任务内容。后台可导入已分配JSON、创建和恢复会话、查看条件/进度/请求/日志、状态框及对应暂停/恢复/跳过休息/结束、000调试跳题、追加备注、导出单会话或全部会话。

导出基于请求开始时的一致捕获，包含events.jsonl、五张CSV、snapshots.json及manifest.json。CSV为UTF-8 BOM，未知时间为空；Mock与真实来源分开。导出ZIP同时在浏览器下载和本机exports目录保存。

基础HTML使用同一API，后续视觉开发只需替换public目录，遵守API.md的可见事件、操作队列、必答和凭据约定。

## 休息、草稿与调试

默认休息180秒；可由被试或实验员跳过。skip_break记录break_skipped而非break_completed，包含实际休息、剩余时长及操作方；管理员操作必须填写原因。

全部主任务的草稿本保存在state.scratchpads[unit_id]，变更写scratchpad_changed。它不经过答案归一化、不执行输入表达式、不参与必答或评分。导出同时提供最终文本及变更次数。

调试000动态复制001配置，由ID、debug标志和copied_from共同校验；正式被试无跳题能力。jump支持任意有效页面，新建page_token并保存debug_jump，保留历史作答和消息去重。所有事件和CSV标识is_debug，manifest列明调试会话。
