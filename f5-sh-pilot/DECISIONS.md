# 当前实验规则

本文定义当前有效的实验约束。原始需求与附件位于 [docs/](docs/)，不得据旧方案覆盖本文；配置操作、界面和设备细节分别见 [CONFIG.md](CONFIG.md)、[FRONTEND.md](FRONTEND.md)、[RAYNEO.md](RAYNEO.md)。

## 正式流程与作答

操作教程 → 情景导入 → 每组说明卡 → U1 → U2 → 消息理解题 → 四项评价 → 休息 → 下一组。共5组10单元；NONE组跳过消息理解题和评价，第五组结束直接完成。

- 主任务、理解题和评价全部必答，无默认选项。正式题答案完整但错误仍可提交，记录评分，不向被试提示正误。
- U1提交前必须实际显示过附件；不要求答对。提交成功后直接进入U2，不添加中间页、延时或按钮。
- 休息默认180秒，被试或主试可跳过，记录实际时长和剩余时间，不伪造已休满。
- 情境时钟从教程第一屏显示第一任务的设定时间；组内不走动，随任务情境更新。

## 消息触发与呈现

- T0：U1附件首次实际呈现（E）；T1：U2首次实际呈现；NONE不发消息。E不是点击时刻，未观察到E不能补发成T1。
- 每个会话每个任务组最多一条正式消息。刷新、恢复、重连及调试跳回不重发，不自动补救失败消息。
- F是SH05 U1首次完整正式提交，与答对无关，不用于触发消息。
- 呈现模式在JSON中逐通知配置并固定为快照，可在同一会话混合。固定时长模式由眼镜从双眼绘制起计时8.5秒；持续模式无声等待主控确认，收到确认立即收起。完整枚举见CONFIG。
- 未确认时允许作答和切页；下一条通知实际触发前必须确认上一条并收到消失证据。忙碌时不覆盖、不排队、不补发。
- 已阅读按钮只表示用户明确确认，不等于注意起点；播放启动不等于实际听到，drawn不等于光学出光。未知时间留空，Mock不伪造真机证据。
- 暂停、问卷和切页不重置眼镜计时；结束会话取消仍在显示的持续消息，并保留异常和原始事件。

## 教程、调试与手动通知

含持续确认模式的会话先完成工具说明、练习通知及须答对的理解题；其他模式只做工具说明。练习使用与正式任务无关的内容；教程数据标记tutorial，独立统计，不并入正式题成绩或正式消息完成率。

000为调试身份，默认五组条件来自原001，可在JSON的debug_participant中配置。只有000被试端可自行跳转；主试后台可为其他会话跳转，保留其正式身份并记录操作。跳回已发消息所在页不会重播，重新完整测试需新建会话。

手动通知允许在会话进行中发送，选择三种呈现模式；关联会话时标记manual，没有会话时独立保存设备记录，不冒充正式刺激。

## 会话与数据

同编号不得同时有两个未结束会话；一副真机眼镜只绑定一个活跃会话。会话创建时固定题目、刺激和配置快照，后来编辑不改变已有会话。操作原因可空，干预仍留痕。删除仅对已结束会话做可恢复标记，不改原始事件；默认列表和全部导出排除已删除会话。

## 材料依据与范围

正式预分配以用户提供的P01—P20配置为基础，不自动分组。Word内嵌Excel已转为原生文本表格；刺激和理解题以属性判断工作簿及批准修订为准，当前内容以运行快照为准。

SH04根据资格、到岗、缺席和人员互斥计算所有合法解，不采用源稿的错误示例。原记录表005—008的版本标题与实际试次顺序不一致时，以试次顺序表为准。其余批准修订统一维护在content/revisions.json及生成脚本，避免文档另存一套题目或答案。

不纳入默认流程：NASA-TLX、录音转写、自动分组、实时生成刺激。语音助手覆盖防护仅处理已确认的包权限，不等同于系统锁定模式；具体机制见RAYNEO。
