# 当前执行规则

原始 PRD 之后由用户做出的决定，与 PRD 冲突时以本文为准。依据：docs/PRD.md、docs/A5 SH任务pilot.docx、docs/刺激材料的属性判断.xlsx。

## 实验流程

- **流程**：INTRO → 每组 CARD → U1 → U2 → 理解题 → 四项评价 → 休息 → 下一组。条件为 NONE 的组跳过两页问卷；第五组结束直接 COMPLETED，没有休息。
- **必答**：主任务、理解题、四项评价全部必答，没有默认选项。答案完整但错误也可以提交，记 0 分，不提示正误。（R5，覆盖 PRD 中主任务可漏答的规则）
- **触发**：T0 = 首次 E（U1 附件实际显示）；T1 = U2 首次实际显示；NONE 不发消息。每个会话的每个任务组最多一条消息，刷新、恢复、000 跳回都不重发。未观察到 E 时不补发为 T1。
- **U1 提交**：U1 提交前必须已实际显示过附件（服务端检查，不要求答对）。U1 提交后直接进入 U2，不加中间按钮或延时。
- **F**：F 指 SH05 U1 的首次完整正式提交，与是否答对无关，不用于触发消息。（R6）
- **眼镜消息**（R4）：只在眼镜上显示，目标 8500 ms，由眼镜端独立计时。程序不发关闭或清屏指令，切页、暂停、问卷、休息都不影响计时，流程也不等待计时结束。
- **未显示的处理**（R3）：消息呈现是实验核心，未显示不算正常完成。暂不实现失败后的补救流程，不以 Mock 或“请求被接受”冒充实际显示；无法得知的显示/消失时间记为 null。
- **休息**：默认 180 秒，被试或实验员都可以跳过，记录实际休息和剩余时长，不伪造“已休满”。
- **调试编号 000**：动态复制当前 001 的配置，被试页和后台都可跳题，跳转留痕，导出标识 `is_debug`。正式编号不能跳题。
- **会话删除**：按单次会话可恢复地删除，须先结束会话；删除后不出现在默认列表和导出中，恢复后保持原来的结束状态。
- **不纳入默认流程**：NASA-TLX、录音转写、自动分组、实时生成刺激。
- **现场**（R1、R2）：在 macOS 开发，现场可能用 Windows；001—004 都保持 V1 预分配，不重新分组。
