# 前端

被试端（`public/experiment.*`、`desktop.css`）和管理端（`public/admin.*`、`app.css`）都是原生 ES module，无构建步骤，符合 CSP。所有研究文案都来自服务端 view，不写进组件。

## 被试端：虚拟办公桌面（Windows 11 浅色风格）

### 窗口与任务栏

- **工作台窗口**：整个流程在一个“工作台”窗口里完成。
- **窗口操作**：窗口只做自动排列，不能拖动或缩放。每个窗口都有最小化、最大化、关闭三个按钮；工作台的关闭按钮置灰。
- **三栏布局**：桌面宽度 ≥1180 px 时，附件在左、工作台居中、草稿本在右，左右两栏同宽；较窄时附件和草稿本浮在工作台上方。
- **任务栏**：
  - 左下角：调试入口，仅 000 可见。
  - 右下角：情景时钟，显示 `scene_time`。时间不走动，在导入、休息、完成页隐藏；换到新的预设时间时闪烁约 3 秒，同一时间刷新页面不重复闪烁。

### 任务页

- **布局**：左边是任务单文档，右边是“填写”区，底部是“下一步”按钮。
  - 内容区宽度 ≥780 px 时左右并排，较窄时上下排列。
- **表格**：标题显示为“表名.xlsx”，带绿色图标。
- **附件**：附件是文件磁贴（.xlsx 绿色、.docx 蓝色），点开后在左侧查看器中显示，关闭即收起。
- **填写区**：
  - 数值和时间字段每行一项，时间提示为 `6:23`。
  - 候选多于 5 个的单选（排班）用下拉框，初始为空；其他选择题用按钮组。
  - 未作答的项会被标出。未打开附件就点下一步时，提示“请先打开附件‘xxx’查看，再进行下一步”。
- **草稿本**：黄色图标的记事本窗口，按单元保存，进入下一单元时为空白，状态栏显示保存状态和字数。
- **排版规则**：只改排版，不改信息。
  - 标题里的全角空格或短前缀冒号拆成小标题加主标题。
  - 段首 ≤6 字的“标签：”显示为标签样式。
  - 原文中的连续空格按换行显示。
  - 评价题末尾的“1分（…）7分（…）”移到刻度两端。
- **休息页**：只显示“分:秒”倒计时。

### 协议实现

- **displayed**：工作台恢复并置顶、文档可见、经过两帧绘制后才报告，用 `generation` 防止旧页面误报。
- **E（reveal_displayed）**：查看器窗口实际显示、未最小化并完成两帧绘制后才报告。刷新时如果附件处于打开状态，先报告工作台可见，再恢复查看器；切页时查看器自动关闭。
- **草稿保存**：答案每次输入都串行保存。草稿本延迟约 450 ms 保存，但在提交、打开附件、切页、关闭窗口、页面隐藏前都会立即保存；页面卸载时用 keepalive 发送，并始终带绑定时的 page_token。

## 管理端 v2

- **桌面**：主从布局。左栏为新建会话、按“进行中 / 已结束”分组的列表、导出全部、已删除会话；右栏为会话详情。
  - 详情主列：实时状态（SH01—05 进度、本组消息分“发送请求 / 眼镜显示”两步）、实验干预（原因必填，危险操作单独分区并需二次确认）、访谈备注。
  - 详情侧列：被试入口、导出当前会话、技术记录（折叠）。
- **手机（约 390 px）**：单列，列表与详情来回切换，支持浏览器返回，触控目标 ≥44 px。
- **其他**：顶栏显示眼镜状态，另有“准备与检查”页（检查结果、配置总表与导入）。
- **主试跳转**：后台对所有未删除会话提供题目跳转，填写原因后执行；目标从后台会话详情读取。正式被试前端不显示调试入口，服务端也拒绝其自行跳转，只有 000 可自行跳题。
- **配置说明**：“准备与检查 → 被试预分配配置”提供 JSON 字段说明与当前配置下载；完整示例见 [CONFIG.md](CONFIG.md)。
- **设备控制**：“准备与检查”包含上位机守护、唤醒并拉回应用、刷新状态、USB 重连、发送测试通知，以及 `scrcpy --crop 640:480:0:0` 左眼调试窗口。通知表单和历史使用独立 DOM，轮询不覆盖正在输入的正文；通知请求有固定 ID，可幂等重试。结果区区分请求接受、双眼绘制、消失和失败，调试通知不会写入被试实验。
- **存储**：被试入口在服务器保存并在浏览器 sessionStorage 缓存；后台直接进入，不保存管理员 key。
- **热点入口**：电脑后台首页展开主试二维码，移动端默认收起，手机扫码直接访问 `/admin`；电脑手动打开被试页面。

## favicon

被试端为 `/favicon.svg`，管理端为 `/favicon-admin.svg`；请求 `/favicon.ico` 时返回被试端图标。
